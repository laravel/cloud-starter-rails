# Rails starter kit

A minimal Ruby on Rails 8.1 app on Ruby 4.0, ready to deploy to [Laravel Cloud](https://laravel.com/cloud) and built as a starting point for coding agents.

```sh
bin/setup --skip-server
bin/dev
```

The app runs on http://localhost:3000. Run the tests with `bin/rails test`.

Agents: read [AGENTS.md](AGENTS.md) first.
